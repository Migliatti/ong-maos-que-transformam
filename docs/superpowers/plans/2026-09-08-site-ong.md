# Site ONG Mãos que Transformam Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar um site acadêmico estático com três páginas semânticas, imagens otimizadas e formulário acessível com máscaras brasileiras.

**Architecture:** Três documentos HTML compartilham uma folha de estilos e navegação consistente. Um módulo JavaScript pequeno contém funções puras de máscara e o comportamento de envio demonstrativo; testes de contrato verificam a estrutura do projeto e testes Node verificam as máscaras.

**Tech Stack:** HTML5, CSS3, JavaScript ES modules, Python `unittest`, Node `node:test`, Pillow e Nu HTML Checker.

**Spec:** `docs/superpowers/specs/2026-09-08-site-ong-design.md`

## Global Constraints

- Usar apenas HTML, CSS e JavaScript sem frameworks ou bibliotecas no navegador.
- Manter exatamente dez campos conceituais de coleta no formulário.
- Validar CPF, telefone e CEP com `pattern`, `maxlength`, `inputmode` e máscara progressiva.
- Fornecer cada fotografia em JPEG e WebP.
- Não armazenar nem transmitir dados pessoais; o envio é demonstrativo.
- Terminar com zero erros estruturais no Nu HTML Checker/W3C.
